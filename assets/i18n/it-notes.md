# Italian (it) translation notes

Standard Italian, informal "tu" throughout; her lowercase voice and full stops kept. Controls use the short imperative (spara, salta, muovi), as Italian games do.

## Terms
- notebook = quaderno, locker = armadietto, backpack/bag = zaino ("my bag" on the ruler = zaino), desk = banco, sketchbook = album da disegno.
- tiny victories = piccole vittorie; tiers bronzo, argento, oro, platino.
- cheat sheet = bigliettino (the school word for a crib note).
- high scores = record; score = punteggio, points = punti; score notes = foglio dei punteggi; my scores / online scores = i miei punteggi / punteggi online; board = classifica.
- wave = ondata, level = livello, round = round, stage = fase, lives = vite, extra life = vita extra, bonus = bonus.
- controller = controller; D-pad = croce direzionale ("croce" in short lines). Keys: Invio, Spazio, Maiusc, Esc, Su/Giù/Sinistra/Destra. On/Off = Sì/No.
- comic = fumetto ("Intro: after updates" = "Fumetto: dopo gli aggiornamenti", avoiding a clash with the Invio key).
- detention = punizione; detention slip = nota di punizione (Italian schools give a "nota"); write it up = mettilo per iscritto.
- principal = preside; Snack-Man staff = quelli della presidenza; sent to the office = in presidenza; substitutes = supplenti; coach = allenatore (prof di ginnastica in the gym report).
- Term Paperboy papers = tesine; course = percorso. quarters = monete. tacks = puntine, chalkboard eraser = cancellino, lunchbox = portapranzo, saucer = disco volante, tank/supertank = carro armato/supercarro, flagship = ammiraglia.
- Joust enemy names (Bounder, hunter, shadow lord), buggy, superzapper, UFO kept.

## Puns and adaptations
- final grade. = voto finale. / class dismissed. = la lezione è finita. / pencils down. = giù le matite. / tardy slip. = sei in ritardo. / say cheese. = sorridi.
- perfect score = un dieci; straight A's = tutti dieci; biology honors = lode in biologia; top marks = voto massimo.
- proof complete = come volevasi dimostrare; divide and conquer = divide et impera; shutout = cappotto (sports slang); hot air = aria fritta; slow and steady = piano piano.
- just another brick. = un altro mattone nel muro.; order up = piatto pronto; touchdown (Lunch Lander) = contatto; page jam = pagina inceppata; the lockers go deeper = sempre più armadietti; brain freeze = cervello congelato; varsity letter = distintivo della squadra.
- defender of the margins = paladina dei margini (hers, feminine); boy heroes' titles are masculine (secchione dell'anno, beccato a cancellare, l'ultimo a uscire).
- "you broke out!" = "evasione riuscita!" (no gender needed).

## Comic
- arcade = sala giochi; ARCADES DON'T CLOSE, KID. / THEY MOVE. = LE SALE GIOCHI NON CHIUDONO, PICCOLA. / TRASLOCANO. (about 145% of the English, please check the balloon).
- Onomatopoeia: PEW = ZAP, BRRRIING = DRIIIN, CLINK = CLING, THOOM = BUUUM!, PUTT-PUTT = TUF-TUF, CHK-CHK = CLAC-CLAC, rain HSSSH = SCIAAA. Kept: ACE, QUARTER MOON (ARCADE), RAD 412,390, the arcade screen texts, tzz, BZZT, PFFT., BLIP, PLOP, FLIP FLIP, GRRRR.
- "STILL TIME." read as a statement (C'È ANCORA TEMPO.). "YOU MADE IT." = CE L'HAI FATTA.
- Narration uses the spoken passato prossimo; lengths are 95% to about 120% of the English in characters (Italian runs a little long).
